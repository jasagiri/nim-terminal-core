# Examples Directory

This directory contains examples demonstrating how to use the Nim Terminal Library.

## Basic Examples

- `hello_world.nim` - Basic terminal usage
- `color_example.nim` - Basic color demonstration
- `basic_colors.nim` - Demonstration of basic, 256, and RGB colors
- `mouse_example.nim` - Mouse input handling
- `signal_handling.nim` - Signal handling demonstration
- `unicode_example.nim` - Unicode text display

## Advanced Examples

- `diff_update_example.nim` - Differential update for efficient drawing
- `minimal_diff_example.nim` - Simplified differential update demo
- `extended_color_example.nim` - Full RGB and 256 color support demo

## Running Examples

To run any example:

```bash
nim c -r examples/basic_colors.nim
```

Most examples can be exited with the `q` key or by pressing `Ctrl+C`.
