# ADR-TC-0001: TUI の枠組み

- 状態: 採用 (2026-10-30)

## コンテキスト
nim-terminal-core は端末の中で動く道具 (lpick、マルチプレクサ、ファイルの一覧、シェルの対話の画面) のための TUI の部品として作られていたが、監査 (nim-terminal-io/docs/audit-2026-10-29-terminal-ui.md) でそのままでは動かなかった。ウィジェットの作り方は 3 通り (継承と method、登録表と pointer、状態の型) が混ざり、データの結びつけは pointer と cast で、端末の層は nim-terminal-io と重なっていた。代表の決定 (2026-10-30) で、TUI の枠組みとして作り直す。端末と話すこと (raw、キーの解読、差分の描画) は nim-terminal-io が持ち、ここでは持たない。

## 決定
module は geometry・canvas・theme・event・widget・layout・binding・shortcuts・app。ウィジェットは委譲で組む: `Widget` は型を継がず、描画・事象・大きさ・子の置き方を `Behavior` (手続きの束) に委ね、具体のウィジェット (Button など) は自分の状態を持つ ref object で、手続きの束がそれを閉じ込める。`ref object of` と method は使わない。規則は次のとおりで、E テストは規則の番号 (`TC-<字>-<番号>`) を名に持つ。

### C: 画布
- **C-1** `put` は書記素クラスタごとに、原点からの位置に書く。切り抜きの外には書かず、切り抜きの端で切れた幅 2 のクラスタは、見える半分を空白にする。幅は Surface の `WidthOptions` (曖昧な幅) で数える。
- **C-2** `put` の戻り値は、切り抜きに関わらず text の幅 (幅 0 のクラスタは `?` として描くので 1)。
- **C-3** `fill` は、矩形と切り抜きの重なりだけを空白で埋める。
- **C-4** `sub` は、矩形を原点とし、切り抜きを矩形と元の切り抜きの重なりにした画布。
- **C-5** `setCursor` は、切り抜きの中なら端末のカーソルの位置を置く。後から置いたものが勝つ。
- **C-6** `fit` は、幅に収まるようクラスタの境で切り、切ったときは末尾を `…` にする (それも入らなければ付けない)。

### L: 割り付け
- **L-1** 縦 (`vbox`)・横 (`hbox`) の箱は、見える子を順に並びの向きへ割り付け、子の間を `gap` だけあける。交わる向きは内側 (padding の内) の全体。
- **L-2** 大きさは、`fixed` (セル)・`percent` (gap を除いた長さの百分率)・`natural` (子が測った大きさ) を先に取り、残りを `fill` に重みで分ける。割り切れない分は前の `fill` から 1 ずつ。箱の測った大きさは、子の測った大きさの和 (並びの向き) と最大 (交わる向き)、gap と padding。
- **L-3** 百分率の端数は、端数の大きい順 (同じなら前から) に 1 ずつ足し、合わせて百分率の和の分 (四捨五入) になる。百分率の和が 100 なら長さをちょうど埋める。
- **L-4** 使える長さを越えたら、後ろの子から削る。大きさは負にならず、子は箱の外に置かれない。
- **L-5** 格子 (`grid`) は、行と列を L-2 で割り付け、子を行の順に升に置く。升より多い子は置かない (見えない)。
- **L-6** 重ね (`stack`) は、全部の子に内側の全体を渡す。後の子が上。
- **L-7** 子の矩形は、割り当てられた所を子の margin だけ縮めたもの。内側は自分の padding だけ縮めたもの。
- **L-8** 見えない子は場所を取らず、矩形も見える所も空。
- **L-9** 割り付けは木と大きさだけで決まる。大きさを変えて割り付け直すと、初めから割り付けたのと同じ。
- **L-10** 各ウィジェットの見える所は、自分の矩形と、親が子を切り抜く矩形 (親の見える所と内側の重なり。`arCustom` は arrange が返す矩形との重なり) の重なり。`arCustom` の arrange が置かなかった子は見えない。

### E: 事象の振り分け
- **E-1** キーは、フォーカスのウィジェットから層の根へ親をたどって渡し、扱われた (handle が true) ら止める。
- **E-2** 誰も扱わなかったキーは、ショートカット (K-4)、Tab・Shift+Tab のフォーカスの移動、Ctrl+C (`quitOnCtrlC` なら終わる)、Ctrl+Z (止める。A-5) の順に試す。
- **E-3** フォーカスの順は、一番上の層の中の、見えて有効で `focusable` のウィジェットの前順。Tab で次、Shift+Tab で前、端で回る。移るとき、前のウィジェットに evFocusOut、次に evFocusIn を渡す。
- **E-4** マウスを押すと、その点の一番深いウィジェット (重なれば後の子) が、自分の左上からの位置で evPress を受け、親へ渡る。押したウィジェットか、その一番近い `focusable` の祖先がフォーカスを得る。
- **E-5** 押した後のドラッグと離すは、押したウィジェットだけが、そのウィジェットの左上からの位置 (外のこともある) で受ける。
- **E-6** 離した点が押したウィジェットの見える所の中なら evClick を渡す (親へ渡る)。同じウィジェットの同じセルへのクリックが、前のクリックから 400 ms 以内なら、その evClick の後に evDoubleClick を渡す。
- **E-7** ホイールは、その点のウィジェットが受け、親へ渡る。フォーカスは動かない。
- **E-8** 層 (`openLayer`) が開いている間、キーとフォーカスはその層の中に留まる。lmModal の層の外のマウスは捨てる。lmPopup の層の外を押すと層を閉じ、その押しはどこにも渡さない。層を閉じると、開く前のフォーカスに戻す (戻せなければ下の層の最初のもの)。
- **E-9** 見えない・無効のウィジェット (と、その子孫) は事象を受けず、フォーカスを得ない。無効のウィジェットの上のマウスは、どこにも渡さない。
- **E-10** 貼り付けは evPaste としてフォーカスから渡り、ショートカットには渡さない。

### K: ショートカット
- **K-1** `parseChord` は `ctrl+s`・`alt+x`・`shift+tab`・`enter`・`q`・`space`・`plus` の形を読む。修飾と名前の大小は問わない。知らない修飾・名前、空、Ctrl と Shift の文字 (端末が区別しない) は、理由つきの失敗。Shift と文字は大文字の文字になる。
- **K-2** `$` は表示の形 (`Ctrl+S`、`Alt+x`、`Shift+Tab`、`Esc`、`PageUp`、`Space`)。
- **K-3** 組み合わせはキーの種類と修飾が同じときに当たる。Ctrl つきの文字は大小を問わない (Alt つきは問う。端末は ESC a と ESC A を区別して送る)。
- **K-4** 積んだ文脈を上から、最後に `global` を探し、最初に当たったものだけを動かす。
- **K-5** 同じ文脈に同じ組み合わせを 2 度は足せない。
- **K-6** `active` は、今効く割り当てを効く順に返し、上の文脈に隠れたものを含めない。

### B: バインディング
- **B-1** `Observable[T]` は、値が変わったときだけ、足した順に購読者を新しい値で呼ぶ。同じ値を入れても呼ばない。
- **B-2** 外した購読者は、以後呼ばない (知らせている途中に外したものも)。
- **B-3** `map` は、元が変わると変わる値を作る。
- **B-4** 2 つを両向きにつないでも、同じ値で止まり、回り続けない (B-1 による)。

### A: アプリ
- **A-1** `run` は端末を raw・代替画面・貼り付けの報告・マウスの報告 (`mouse`、既定はドラッグまで)・カーソルを隠すにして、quit されるか SIGTERM・SIGHUP・SIGINT が届くまで回す。どの終わり方でも端末を戻す。シグナルで終わったときは、その番号を返す。
- **A-2** 端末の大きさが変わる (SIGWINCH) と、新しい大きさで割り付けて全部を描き直す。
- **A-3** 描くのは、根、層の順 (層が上)。端末へは前の画面との差分だけを送る (nim-terminal-io の `render`)。
- **A-4** `every` のタイマーは、時が来るたびに 1 度動く。遅れても取り返して何度も動かさない。`cancel` すると止まる。
- **A-5** 誰も扱わなかった Ctrl+Z と SIGTSTP では、端末を戻して止まり、続けられたら端末を戻し直して全部を描き直す。
- **A-6** 端末のカーソルは、フォーカスのウィジェットが描くときに置いた所に出す (日本語の入力の変換の窓がそこに出る)。置かなければ隠す。

## 採らなかった案
- **継承と method でウィジェットを作る** (前の版): 開発の規則は委譲を求める。手続きの束なら、ウィジェットの種類を足すのに枠組みの型を変えない。
- **ウィジェットの描き手の登録表** (前の版の registerXWidget): 手続きの束をウィジェットが直に持てば要らない。
- **pointer と cast のデータの結びつけ** (前の版の DataContext): `Observable[T]` は型で値を守る。
- **一部だけを描き直す (無効化の印)**: 毎回全部を描き、端末へは差分だけを送る。木の大きさは画面の大きさで決まり、描くのは安い。差分は nim-terminal-io の `render` が持つ。
- **Textual のような CSS**: 役割ごとのスタイル (Theme) で足りる。身の丈に合わない。
- **枠組みの中の非同期 (async)**: 待つのは端末とシグナルの 2 つで、select で足りる。重い処理は呼び手が別のスレッドかプロセスで行い、タイマーで結果を拾う。
- **升をまたぐ格子の子**: 要るまで作らない。
