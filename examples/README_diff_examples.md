# 差分更新デモサンプル

このディレクトリには、ターミナルライブラリの差分更新機能を示すサンプルが含まれています。

## サンプル一覧

1. **diff_update_example.nim** - 差分更新の効果を視覚的に示す完全な例
   - 画面分割による比較
   - パフォーマンス計測
   - 豊富な視覚効果

2. **minimal_diff_example.nim** - より単純な差分更新デモ
   - 依存関係の少ない実装
   - キーボード制御によるモード切替
   - パフォーマンス情報の表示

## 差分更新の利点

差分更新アルゴリズムは以下の利点を提供します：

- **効率性**: 変更された部分のみを更新
- **ちらつき減少**: 必要な箇所だけの描画でちらつきを軽減
- **帯域幅節約**: リモート接続時のデータ量削減

## コンパイルと実行

```bash
# 標準版（フル機能）
nim c -r examples/diff_update_example.nim

# 最小版（依存性が少ない）
nim c -r examples/minimal_diff_example.nim
```

## 使用方法

- Qキーで終了
- minimal_diff_exampleではスペースキーで描画モードを切り替え
