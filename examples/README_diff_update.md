# 差分更新デモ

このサンプルは、端末描画における差分更新アルゴリズムの効果を視覚的に示します。

## 概要

このデモは画面を2つの領域に分け、それぞれで異なる描画方法を使用します：

1. **左側**: 従来の描画方法（全体再描画）
2. **右側**: 差分更新を使用した最適化描画

両方の領域に同一のランダムな更新を適用し、それぞれの描画にかかる時間を測定・表示します。これにより、差分更新がどれだけ効率的であるかを直接比較できます。

## 機能

- ランダムなセルの色更新
- パフォーマンス測定と表示
- リアルタイムな効率比較

## 実行方法

```bash
nim c -r examples/diff_update_example.nim
```

## 仕組み

1. 画面を2つの領域（ボックス）に分割
2. 各更新サイクルで同じランダムな変更を両方のボックスに適用
3. 左側は全画面再描画方式で描画
4. 右側は差分更新アルゴリズムで描画
5. 各方式の処理時間を測定して表示
6. 効率の比率を計算して表示

## 期待される結果

変更が少ない場合、差分更新は従来の方式と比較して数倍から10倍以上速くなることが期待されます。これは特に大きな画面や複雑なレイアウトを持つアプリケーションで顕著です。

## Qキーで終了

実行中にQキーを押すとデモが終了します。
